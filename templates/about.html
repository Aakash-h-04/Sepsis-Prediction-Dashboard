PROJECT ARCHITECTURE & MISSION

Building healthcare technology with complete transparency.

SepsisSense unites public health awareness, interactive biomedical education, and an end-to-end IoT-to-cloud machine-learning architecture into a cohesive, production-grade web platform.

Project Motivation & Problem Statement

Sepsis affects nearly 49 million individuals annually, resulting in roughly 11 million global deaths (~20% of all global mortality). Despite its prevalence, public awareness of sepsis warning signs remains dangerously low. Simultaneously, while AI and IoT monitoring hold immense potential for early physiological alerting, experimental healthcare models are frequently obfuscated behind exaggerated marketing or opaque black-box interfaces.

SepsisSense was engineered to solve both challenges: provide accessible, scientifically rigorous public education while demonstrating full engineering transparency for an experimental vital-sign machine-learning pipeline.

System Architecture & Component Flow

  1. Edge Telemetry (ESP32): An edge microcontroller captures vital signs (Heart Rate, Temperature, SpO2) and dispatches TLS-encrypted JSON payloads every 5 seconds to POST /api/readings.
  2. Backend Web Server (Python Flask & Gunicorn on Render): Validates numerical ranges and finite bounds, safeguards API compatibility, and coordinates storage and inference.
  3. Machine Learning Pipeline (Scikit-learn Random Forest): Re-maps incoming keys into feature order [HR, O2Sat, Temp], passes inputs through median imputation and 200 decision trees, and evaluates class probability against a tuned 0.01 threshold.
  4. Database & Session Persistence (SQLite & PostgreSQL Compatible): Stores sensor readings, registered edge devices, user credentials with secure hashing, notification preferences, chat logs, and administrative audit trails.
  5. Multilingual AI Assistant & Speech Avatar: Dynamic dual-mode assistant supporting English, Hindi, Tamil, and Kannada with Web Speech API voice input and SpeechSynthesis vocalization.
  6. Automated Alert Integrations: Server-side notification services supporting Gmail API / SMTP and Twilio WhatsApp delivery.

Scientific & Clinical Limitations

SepsisSense strictly upholds medical safety. The deployed Random Forest model was trained on exploratory row-level PhysioNet Challenge data. Because sepsis is relatively rare in hospital stays, the holdout test set demonstrates a precision of 3.70% and a ROC-AUC of 0.5854. These metrics highlight that sensor vitals alone cannot diagnose sepsis; clinical diagnosis requires laboratory cultures, organ failure biomarkers (lactate, creatinine, platelets), and licensed medical evaluation.

Future Work

Future iterations aim to incorporate multimodal continuous time-series modeling (e.g. LSTM / Transformer architectures), wearable Bluetooth Low Energy (BLE) peripheral pairings, and automated laboratory EHR integrations under HIPAA/FHIR compliance standards.
