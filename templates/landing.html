Engineered Data Pipeline

From ESP32 edge telemetry to cloud classification.

How physiological data moves through the hardware, network, backend, and machine-learning layers in real time.

01 / EDGE INGESTION

ESP32 Microcontroller

Reads BPM, Temperature, and SpO₂ every 5 seconds. Sends JSON over secure TLS to POST /api/readings.

02 / BACKEND API

Flask on Render

Validates numerical bounds and finite constraints. Routes payload to the persistent database and prediction service.

03 / INFERENCE ENGINE

Random Forest Pipeline

Re-orders features to [HR, O2Sat, Temp]. Computes sepsis probability using 200 estimators against a 0.01 threshold.

04 / OBSERVABILITY

Real-Time Dashboard

Stores readings and displays live vitals, risk flags, and historical trend charts for ongoing monitoring.

Responsible AI & Transparency

Real experimental metrics, zero false claims.

Clinical machine learning requires total transparency. The current experimental Random Forest exhibits low precision due to extreme class imbalance.

Validation ROC-AUC 0.5785 Patient-level validation
Test Accuracy 59.61% Holdout test set
Test Recall (Sensitivity) 55.32% 26 of 47 positive cases
Test Precision 3.70% Severe class imbalance
💡
Why is precision only 3.7%? Sepsis occurs in a very small fraction of hospital hours (~2-3%). A low classification threshold (0.01) was selected to prioritize catching positive cases (55.3% recall), but this inherently results in many false positives (677 false positives). This demonstrates why sensor-only models cannot be used clinically without comprehensive laboratory and clinical context.
